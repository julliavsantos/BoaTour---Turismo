## 🌎 Sobre o projeto

O BOATOUR é um site de agência de turismo desenvolvido como projeto
acadêmico, com o objetivo de proporcionar uma experiência completa
de planejamento de viagens.

## 🚀 Funcionalidades

- 🗺️ Exploração de destinos
- ✈️ Pesquisa de voos
- 🏨 Pesquisa de hotéis
- 🎯 Atividades turísticas
- 💰 Ofertas
- 🧠 Quiz de destinos
- 👤 Perfil do usuário
- 💳 Área de pagamentos
- 💬 Chatbot
- 🔔 Sistema de notificações

## 💻 Tecnologias

| Tecnologia | Utilização |
|---|---|
| HTML5 | Estrutura |
| CSS3 | Estilização |
| JavaScript | Interatividade |
| PHP | Back-end |
| MySQL | Banco de dados |
| Git | Versionamento |
